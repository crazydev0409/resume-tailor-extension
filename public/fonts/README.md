# Bundled resume fonts

These fonts are packaged locally, embedded into PDFs, and loaded on demand.
Each family includes regular, bold, and italic TrueType files. The adjacent
LICENSE/OFL files contain the redistribution terms and copyright notices.

| Requested choice | Embedded font |
| --- | --- |
| Arial | Arimo |
| Calibri | Carlito |
| Aptos | Lato (visual alternative, not metrically equivalent) |
| Helvetica | Arimo |
| Roboto | Roboto |
| Georgia | Gelasio |
| Garamond | EB Garamond |
| Cambria | Caladea |
| Times New Roman | Tinos |
| Verdana | Open Sans (visual alternative, not metrically equivalent) |

Alternative names are also displayed in the font selector. These are distinct
typefaces, not copies of the proprietary fonts.
